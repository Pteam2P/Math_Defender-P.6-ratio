# Math Defender: ภารกิจอัตราส่วนและร้อยละ (ป.6)

ระบบเกมเพื่อการศึกษาแบบ Single-file Web App ที่ถูกออกแบบตามหลักการ **Pedagogy in Education** และ **Gamification** สามารถนำไปฝังบน GitHub Pages หรือ Google Sites เพื่อให้นักเรียนใช้งานได้ทันที

## ลูกเล่น (Gimmicks) ที่เพิ่มเข้ามา:
1. **ระบบ Critical Hit:** มีโอกาส 20% ที่นักเรียนตอบถูกแล้วจะตีบอสแรงขึ้น 2 เท่า (สุ่ม) กระตุ้นความตื่นเต้น
2. **ระบบฉายาเปลี่ยนตาม Combo:** หากตอบถูกติดกัน ฉายาจะเปลี่ยนจาก "นักคณิตฝึกหัด" เป็น "ปรมาจารย์อัตราส่วน" พร้อมสีสันที่เปลี่ยนไป
3. **ระบบสุ่มคำถาม (Randomized Questions):** เล่นกี่รอบ ลำดับคำถามและตำแหน่งตัวเลือกจะไม่ซ้ำกัน ป้องกันการจำตำแหน่ง
4. **เอฟเฟกต์แอนิเมชัน:** จอสั่นเมื่อตอบผิด (Shake Effect) และตัวละครลอยตัว (Floating Effect)
5. **เนื้อหาวิชาคณิตศาสตร์ ป.6:** 10 ชุดคำถามเรื่อง อัตราส่วนและร้อยละ ที่ใช้หลักการ Distractors (ตัวเลือกลวงที่ดักตรรกะผิดๆ ที่เด็กมักเข้าใจผิด)

## โครงสร้างไฟล์
โฟลเดอร์นี้จัดเตรียมไว้เพื่อนำไปอัปโหลดขึ้น **GitHub** ใช้งานผ่านฟีเจอร์ GitHub Pages ได้ทันที

- `index.html` - โค้ดตัวเกม (รวม HTML, CSS, JS ไว้ในไฟล์เดียวเพื่อความง่าย)
- `images/` - โฟลเดอร์สำหรับใส่รูปภาพ (คุณครูสามารถนำรูปมาใส่แทนที่ได้)
  - `bg/` (แนะนำขนาด 1280x720px แบบ JPG)
  - `hero/` (แนะนำแบบ PNG พื้นหลังใส)
  - `boss/` (แนะนำแบบ PNG พื้นหลังใส)
  - `logos/` (โลโก้โรงเรียน หรือองค์กร)

## วิธีการใช้งานร่วมกับ GitHub
1. สมัคร/เข้าสู่ระบบ GitHub และสร้าง Repository ใหม่
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดนี้ขึ้นไปบน Repository
3. ไปที่เมนู **Settings** -> **Pages** (เมนูด้านซ้าย)
4. เลือก Branch: `main` (หรือ `master`) แล้วกด Save
5. รอสักครู่ (1-2 นาที) GitHub จะสร้างลิงก์สำหรับเข้าเล่นเกม เช่น `https://[ชื่อคุณ].github.io/[ชื่อโปรเจกต์]/` นำลิงก์นี้ส่งให้นักเรียนเล่นได้เลย!
